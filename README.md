# Sunday Script

A daily final-drive football game with a TV-broadcast look. Call the plays and watch them (Coach mode), or play quarterback yourself (Player mode).

Play it: https://driscollglobe.github.io/sunday-script/

This repository is the published build. Credits for the player model and animations: [assets/models/CREDITS.md](assets/models/CREDITS.md). The player model is "American Football Player" by blakeallen25 (CC-BY-4.0), modified. Team names, logos and wordmarks belong to their owners; this is an unofficial fan project.
